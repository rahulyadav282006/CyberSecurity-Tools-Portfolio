# URL Security Analyzer & Phishing Threat Detector

## 1. Concept Overview
- **Category**: Level 3 – Web Security & Threat Intelligence Fundamentals
- **Cybersecurity Concept**: Phishing Detection, Lexical URL Forensics, Shannon Entropy (DGA Detection), Levenshtein Distance (Typosquatting), HTTP Redirect Unmasking
- **Key Modules**:
  1. **Lexical & Structural Analysis**: Identifies plaintext HTTP, raw IP hosts, `@` symbol credential tricks, and sensitive path keywords (`login`, `verify`, `account`).
  2. **Shannon Entropy Engine**: Calculates character randomness in bits. Flags high entropy (> 3.8 bits) domains generated by Domain Generation Algorithms (DGAs).
  3. **Levenshtein Distance Matcher**: Catches character-substitution brand impersonations (e.g. `paypa1.com` imitating `paypal.com` at edit distance 1).
  4. **Subdomain Deception Detector**: Exposes links like `secure.apple.com.account-update.xyz` where the brand name is placed in the sub-domain to deceive the user.
  5. **Safe HTTP Redirect Unmasker**: Recursively follows HTTP 301/302 redirects to reveal cloaked landing destinations behind URL shorteners (`bit.ly`, `tinyurl.com`).
  6. **Actionable Decision Engine**:
     - **0% – 25% [🟢 LOW RISK]**: `SAFE TO PROCEED` (Standard browsing allowed).
     - **26% – 59% [🟡 MEDIUM RISK]**: `PROCEED WITH CAUTION` (Quarantine / Do not enter credentials).
     - **60% – 100% [🔴 HIGH RISK]**: `STRICTLY PROHIBITED (BLOCK & ISOLATE)` (Immediate firewall & mail gateway block).

## 2. Mathematical Formulas Used in this Code 

This project implements two core mathematical and information-theory formulas:

### A. Shannon Entropy Formula ($H$)
Used in `calculate_entropy(text)` to quantify the lexical randomness of a domain and detect **Domain Generation Algorithms (DGA)**:

$$H(X) = - \sum_{i=1}^{n} P(x_i) \cdot \log_2 P(x_i)$$

Where:
- $n$: Total number of unique characters appearing in the domain.
- $P(x_i)$: The probability (frequency) of character $x_i$ occurring in the string.
- $\log_2$: Base-2 logarithm, measuring uncertainty in **bits**.

**Cybersecurity Thresholds**:
- Human-created domains (e.g., `google.com`, `github.com`): **Entropy $\approx$ 2.3 to 2.8 bits** (Low randomness / predictable language).
- Machine-generated bot/DGA domains (e.g., `xq97z-payp1-auth.biz`): **Entropy $\ge$ 3.8 bits** (High randomness / automated malware C2).

---

### B. Levenshtein Distance Matrix Formula
Used in `levenshtein_distance(s1, s2)` to quantify the minimum single-character edit distance for **Brand Typosquatting Detection**:

$$\text{lev}(a, b) = 
\begin{cases} 
|a| & \text{if } |b| = 0, \\
|b| & \text{if } |a| = 0, \\
\text{lev}(\text{tail}(a), \text{tail}(b)) & \text{if } a[0] = b[0], \\
1 + \min \begin{cases} 
\text{lev}(\text{tail}(a), b) & \text{(Deletion)} \\
\text{lev}(a, \text{tail}(b)) & \text{(Insertion)} \\
\text{lev}(\text{tail}(a), \text{tail}(b)) & \text{(Substitution)} 
\end{cases} & \text{otherwise.}
\end{cases}$$

**Cybersecurity Thresholds**:
- **Distance = 0**: Exact match to legitimate brand.
- **Distance = 1 or 2**: High-probability brand impersonation (e.g., `paypa1` vs `paypal` = 1, `arnazon` vs `amazon` = 1, `g00gle` vs `google` = 2).
